# 毒蘑菇留观联络网

本仓库保存区域中毒救治中心「聚集事件与留观后端」的领域资料与最小事件约定，供业务团队在统一语义上继续建设。

## 已有内容

- `contracts/domain.schema.json`：领域事件的基础字段、聚合类型和事件名称。
- `data/sample.json`：可用于联调的中文样例记录。
- `data/autumn_rain_scenario.json`：秋雨后同桌聚餐者分散就诊的完整事件流（含自行离院、手机识图线索、剩余样本送检、临时身份、误并撤销、检验更正与跨院重发）。
- `src/`：领域核心，分为存储、投影、计划、命令、视图五层（见下）。
- `tests/`：验证样例、约定与领域不变量保持一致。

## 模块

- `src/validator.py`：校验事件信封与各事件类型的必备负载，拒绝挂错聚合的数据。
- `src/store.py`：事件存储。按 `event_id` 幂等去重，跨院重发不产生重复效果；同一 `event_id` 携带不同内容视为冲突；读取按 `(occurred_at, version, event_id)` 稳定排序，同一秒的事件以聚合内版本还原因果。
- `src/aggregates.py`：由事件流推导聚集事件（就餐批次、同餐关系、采集地点、剩余样本）、患者留观（症状时间线、检验、医嘱、转院、联络）、样本链路（去向与毒检）与合并记录。
- `src/toxins.py`：毒素类别的潜伏期、留观窗口与关键复查间隔参考数据。
- `src/plan.py`：留观计划推导。疑似毒素取「患者线索 ∪ 同起事件样本毒检」的并集，完全没有信息时按未明毒素最严口径；计划只依赖共享事件，任何医院读到相同事件都会得到相同安排。
- `src/commands.py`：命令侧不变量——检验更正必须指向本留观原始结果；临时档案只能并入已确认档案，撤销引用原合并事件；解除观察必须通过窗口与关键复查校验并写入医学依据；`emit_scan_events` 以内容决定事件 id，重复扫描幂等。
- `src/views.py`：值班视图按危险窗口排序，呈现样本去向、尚未联系的同餐者与缺失复查；疾控汇总只保留必要地点与人数。

## 领域约定

- 事件一旦被接收，其标识、发生时间和版本不应被原地改写；业务更正应产生后继记录。
- 外观描述或手机识图只记作线索（`CLUE_RECORDED`），不构成诊断结论；剩余样本毒检（`TOXIN_IDENTIFIED`）沿样本链路登记。
- 症状暂缓（假愈期）不能结束观察：解除观察（`OBSERVATION_CLOSED`）要求疑似毒素的危险窗口已过、潜伏期后的关键复查齐全，且 `basis` 引用本留观的检验结果与医师理由，每次解除都能回到医学依据。
- 不同毒素的潜伏窗到期前若缺关键复查，`emit_scan_events` 产生 `ESCALATION_RAISED` 升级联络；到期复查产生 `FOLLOWUP_DUE`。
- 身份未确认时以 `PROVISIONAL_IDENTITY_OPENED` 建临时记录；`EPISODES_MERGED` 的错误合并可用 `EPISODE_MERGE_REVERTED` 撤销，双方档案恢复独立。
- 检验更正（`LAB_RESULT_CORRECTED`）与原始结果同时保留，读取默认取最新有效值，历史完整可查。
- 涉及个人、机构或商业敏感信息时，调用方只读取完成职责所必需的字段；疾控视图只汇总必要地点与人数。
